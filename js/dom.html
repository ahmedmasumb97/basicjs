DOM

Document:Refers to the web document (usually an HTML or XML file) that is being displayed in the browser. The DOM represents this document as a structured format that can be manipulated.

Object:The document is modeled as a collection of objects or nodes. Every element (like a paragraph, image, or link) is treated as an object that can be accessed and modified. In JavaScript, for example, these objects have properties and methods you can interact with.

Model: The DOM creates a model or tree-like structure of the document, where each node is a representation of the parts of the document. This hierarchical model allows developers to navigate and manipulate the structure and content of the document.

What is the HTML DOM?

The HTML DOM is a standard object model and programming interface for HTML. It defines:

  • The HTML elements as objects
  • The properties of all HTML elements
  • The methods to access all HTML elements
  • The events for all HTML elements

In other words: The HTML DOM is a standard for how to get, change, add, or delete HTML elements.
